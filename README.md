An [Agent Skill](https://agentskills.io) that teaches any AI coding agent to direct **MiniMax H3** video generation on a local **FreeVideo** install: write prompts in the official H3 format, pick the right mode, plan and submit jobs, build long videos, and check the result — all on your own graphics card.

## What it does

- **Prompts in the official H3 format** for all five modes: T2VA (text), I2VA (first frame), FL2VA (first + last frame), L2VA (last frame) and Ref2VA (characters, places and voices from references) — with the exact keyframe-alignment lines, shot timing `[Shot N] At MM:SS.mmm`, camera vocabulary, sound and music sections.
- **Speech generated by the model.** Dialogue goes into `<d>[Russian] …</d>` / `<d>[English] …</d>` with stable speaker IDs; H3 voices it with lip sync. Rules against unwanted subtitles.
- **Long videos, chosen per task:** a new shot from references (default for films), last frame → first frame of the next clip, `continue_from`, or one job up to 60 s that FreeVideo splits and joins. Guidance for even motion speed across seams.
- **FreeVideo engine knowledge:** quality tiers (`light` = two-pass 8+3 … `max` = 20 steps), `sampling`, LoRA, the 24 fps / 17n+5 frame grid, per-machine time estimates from `/capabilities`, idempotent submissions.
- **Safe helper** `freevideo.py` (Python stdlib only): loopback only, never prints the token, no blind retries, writes require `--apply`.
- **Practice notes** from real local generations and eight style recipes adapted from the official MiniMax-H3 skills.

## Requirements

- FreeVideo (a local MiniMax H3 studio on ComfyUI) running with its Agent API (`http://127.0.0.1:8188/freevideo/agent/v1`) and its bearer-token file. About running H3 locally: [MiniMax local deployment guide](https://platform.minimax.io/docs/guides/local-deploy-h3.md). Writing prompts alone needs nothing.
- Python 3.10+ for the helper. Any GPU FreeVideo supports; generation time comes from your machine's `/capabilities`.

## Install

```bash
git clone https://github.com/sergekostenchuk/minimax-h3-skill
cd minimax-h3-skill
python install.py --target agents        # ~/.agents/skills — Codex, Gemini CLI, Qwen Code, Kimi, pi, OpenCode, Cursor, Roo, Goose, Copilot, Devin, Grok Build
python install.py --target claude-code   # ~/.claude/skills
python install.py --all                  # agents + claude-code + hermes + antigravity + cline
python install.py --list                 # every target and its folder
```

`--dry-run` shows what would be written. Or copy `skill/minimax-h3` into your harness's skills folder by hand.

## Use

Ask your agent in plain words:

> Make a 10-second video: a woman on a beach at sunset looks at the sky and says in Russian "Многое изменится". The camera slowly rises. No music, no subtitles.

The agent writes the H3 prompt, runs `POST /plan` (actual length, warnings, time estimate), submits only when you asked for a video, waits, downloads and checks the result. Ask for "just the prompt" to get text only.

Helper by hand:

```bash
python -B skill/minimax-h3/scripts/freevideo.py get /capabilities
python -B skill/minimax-h3/scripts/freevideo.py post /plan --json skill/minimax-h3/assets/job-t2va.json
python -B skill/minimax-h3/scripts/freevideo.py post /jobs --json job.json --apply
```
