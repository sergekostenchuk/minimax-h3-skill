# FreeVideo Agent API — адаптер

Используй локальный Agent API, не `/prompt` ComfyUI. Значения ниже сверены с `/guide`, `/schema` и `/capabilities` FreeVideo 0.4.x; после обновления движка перечитай `GET /guide` и `GET /capabilities` один раз.

## Подключение

Helper: `python -B scripts/freevideo.py [--base URL] [--token-file PATH] get|post ENDPOINT [--json FILE] [--apply] [--save PATH]` (`--base`/`--token-file` — перед методом).
Base по умолчанию: `http://127.0.0.1:8188/freevideo/agent/v1`. Токен: `~/FreeVideo/FreeVideo-engine/agent/token`; при другой установке путь подскажет `GET /connect` или `custom_nodes/FreeVideo/freevideo-launcher.json` (`engine_root`). Содержимое токена не показывай и не помещай в командную строку.
GET разрешены: `/`, `/schema`, `/openapi.json`, `/guide`, `/capabilities`, `/queue`, `/jobs`, `/jobs/<id>`, `/library`, файлы library и input. POST: `/plan`, `/media/inspect` — без `--apply`; `/jobs`, `/media`, `/media/frame` — только с `--apply`. Отмена, resume, gpu/release, настройки — не через helper.

## Возможности машины

`GET /capabilities` → `machine` (GPU, VRAM, RAM), `sizes`, `lengths` (секунды → кадры), `tiers` (качество и `estimate_seconds` — оценка времени генерации на ЭТОЙ машине по размеру и длине), `summary` (размер и предел по умолчанию). Время генерации сильно зависит от видеокарты: бери оценку отсюда или из `/plan`, а не из чужих замеров.

## Качество

| quality | Как считается |
|---|---|
| `light` (по умолчанию) | two-pass: 8 шагов первого прохода на половинном размере + 3 шага доводки в полном |
| `medium` | те же 8 + 3, первый проход крупнее — больше деталей, дольше |
| `high` | 16 шагов, один проход, с кэшем шагов |
| `max` | 20 шагов, один проход, с кэшем шагов |

`sampling: {two_pass, base_steps (1–32), refine_steps (1–31)}` — ручная настройка. Two-pass работает только с 8 шагами первого прохода; иные `base_steps` идут одним проходом. `two_pass: false` без `base_steps` = 20 шагов.
Продолжение (`continue_from`) и многочастные ролики требуют two-pass: `light`, `medium` или `sampling.two_pass=true`, без `preview`.
`preview: true` — быстрый черновик (всегда two-pass 8); затем `refine_from: "<job id>"` — второй проход того же черновика.
`seed` — целое; одинаковые seed, промпт, media и параметры на той же установке дают тот же результат. `null` — случайный.

## Размеры и длительность

- `width`/`height` кратны 32 (256–4096) **или** `aspect` (например `"9:16"`) + `megapixels`; одновременно нельзя. Родной размер ~0,98 Мп: 1344×768, вертикаль 768×1344. Неровный размер пользователя → ближайшие кратные 32 (1000×560 → 992×544 / 992×576).
- Видео 24 fps, число кадров по сетке **17n+5**: запрошенные секунды округляются вверх до сетки (6 с → 6,583 с; 10 с → 10,125 с; 15 с → 15,083 с; 20 с → 20,04 с). Таймкоды планов и S.SS в инструкции привязки считай по фактической длительности из `/plan`. Пользователю называй реальную длину в секундах, без объяснения кадров.
- 4–15 с — проверенный диапазон одной части; до 60 с в одной задаче — части и склейка автоматически (см. `continuity.md`). Предел машины — в `/plan` (`continuation_unavailable` — продолжение не поддерживается этой установкой).

## media

- `first` / `last`: имя файла из `/media` (`"file"`), или объект `{"file"}`, `{"from_job": "<id>", "frame": "first"|"last"|секунда}`, `{"library": "<YYYY-MM-DD/32hex>", "frame": ...}`; плюс необязательный `edit` (crop / rotate / flip / pad) — кадрирование под новый план.
- `references`: список картинок/видео/аудио (Ref2VA; клипы обрезаются до 15 с). Для многочастного ролика — до 3 картинок, их видит каждая часть.
- Загрузка своего файла: `POST /media` с `{"name": "ref.png", "data_base64": "..."}` (`--apply`); HTTP не принимает локальные пути. В задании используй возвращённый `file`. Base64 не выводи в чат.
- Отдельно извлечь кадр (например, чтобы осмотреть его): `POST /media/frame` с `{"source": {"library": "...", "frame": "last"}}` (`--apply`), затем скачать `url`.

## LoRA

`loras: ["name.safetensors"]` или `[{"name": "name.safetensors", "strength": 0.8}]` (−4…4, до 32 штук). Только файлы, уже установленные в FreeVideo; список и совместимость сверяй по `/schema`/`/capabilities`. Не скачивай LoRA без поручения.

## Запуск, ожидание, получение

```bash
python -B scripts/freevideo.py post /plan --json job.json
python -B scripts/freevideo.py post /jobs --json job.json --apply
python -B scripts/freevideo.py get '/jobs/j0123456789ab?wait=25'
python -B scripts/freevideo.py get '/library/2026-01-01/aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa/file' --save result.mp4
```

ID в примере вымышленные. Helper перед `/jobs` делает `/plan`, при warnings не отправляет; один POST; читает созданный ID. Рекомендуется `label` (короткое имя ролика) и `ref` (ключ идемпотентности): повтор с тем же `ref` и содержимым вернёт то же задание, а не новую генерацию.

**Warnings и отправка job.** Помощник блокирует `POST /jobs`, пока `/plan` вернул хоть один warning. Для локального r2v (`media.references`) FreeVideo всегда отдаёт warning `Reference generation is experimental` — это постоянное свойство режима, а не ошибка конкретного промпта. Чтобы отправить такой job, укажи точное текстовое совпадение: `--accept-warning "Reference generation is experimental"`. Совпадение должно быть дословным; любое другое предупреждение продолжает блокировать отправку. Принятые warning возвращаются в ответе как `accepted_warnings` — их нужно пересказать в отчёте, а не выдавать за отсутствие ограничения.
Статусы: waiting/running → succeeded | failed | cancelled | interrupted. `wait` не больше 25 с, опрашивай тот же ID. Обрыв ожидания не отменяет генерацию. Упавшую или прерванную генерацию продолжает `POST /jobs/<id>/resume` (готовые части сохраняются) — по решению пользователя.
Результат: `result.video.url`, `library_id` склейки и каждой части. `--save` пишет только новый файл, проверяет тип и размер, считает SHA-256 — это транспортная проверка; дальше ffprobe/декодер, кадры и звук.

## Видеопамять

После ролика модель остаётся в видеопамяти для быстрого следующего запуска и уходит сама, когда память нужна другой программе. Если между генерациями на той же карте работает своя модель агента — `release_gpu_after: true` в задании. Не освобождай GPU во время чужой генерации.

## Другие возможности (не через этот helper)

Проекты и монтаж (`/projects`: вставка, экспорт, субтитры через listen, общая музыка через music), импорт своих клипов (`/imports`), редактор картинок (`/images`, `remove_text`), карточки персонажей (`/cast`), фильмы из планов с дублями (`/drama`), черновой 3D-макет камеры (whitebox — только по просьбе пользователя), проверка кадров локальной VLM. Перед использованием читай соответствующий раздел `GET /guide`; не обещай их без проверки на этой установке.
