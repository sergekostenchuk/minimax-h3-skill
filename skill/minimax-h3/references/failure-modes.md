# Failure modes / Retry policy

| failure_mode | Действие и предел |
|---|---|
| tool_unavailable | Проверить endpoint один раз; предложить только промпт/план. Не устанавливать движок самовольно. |
| permission_blocked | 401/403, нет token file или разрешения: остановить записи; не просить секрет в чате. |
| timeout | GET можно повторить один раз. POST не повторять без сверки /jobs; повтор — только с тем же `ref`. |
| partial_output | Есть job, нет скачанного/проверенного видео: сохранить ID, один раз попробовать получение; не объявлять результат готовым. |
| schema_mismatch | Прочитать `details` ошибки и нужный раздел схемы; максимум две содержательные коррекции. Не пересылать неизвестные поля. |
| plan_warning | `/plan` вернул warning. Для r2v это постоянное `Reference generation is experimental`: принять точным `--accept-warning "Reference generation is experimental"` и отметить в отчёте, что режим экспериментальный. Любой другой warning — сначала выясни причину, не отправляй job вслепую. |
| continuation_unavailable | Установка не умеет продолжение/части: одна часть в пределе из /plan, либо цепочка «последний кадр → media.first». |
| out_of_memory | Использовать альтернативы из ответа (меньше размер или длина), согласовав с пользователем; чужие процессы не убивать. |
| bad_take | Непрошеные субтитры, сломанный текст, дрейф лица, рывок на стыке: другой seed; после двух неудач — переписать описание, а не повторять тот же запрос. |
| security_blocked | Не снимать защиту loopback, не выводить token, не обходить фильтры, не ставить неизвестные пакеты. |
| encoding_error | Ошибка `charmap`/`UnicodeEncodeError` в консоли Windows: helper печатает UTF-8 сам; для других скриптов — `PYTHONIOENCODING=utf-8`. |
| stale_data | После обновления FreeVideo заново прочитать `/guide`, `/capabilities`, `/plan`; старые лимиты — не доказательство. |
| ambiguous_scope | Спросить только о роли исходника, правах/согласии или несовместимых вариантах результата. |
| hallucinated_source | Удалить неподтверждённое утверждение, восстановить реальное доказательство. |

Проверка одного неизменного поля схемы не должна превращаться в цикл. Polling активного job — ограниченное ожидание, а не повторная генерация. Уменьшение разрешения или длины, меняющее явное требование пользователя, согласуй.
