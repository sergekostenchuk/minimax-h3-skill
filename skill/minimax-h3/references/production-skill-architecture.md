# Runtime architecture / Tool verification

Один видимый скилл: minimax-h3. Рецепты и справка внутри него; upstream Hub skills не устанавливаются как отдельные зависимые роли.

## Dependency states

- Python 3.10+ со стандартной библиотекой: required для helper; проверить `python --version`.
- FreeVideo API и существующий token file: required только для выполнения; проверять перед каждым новым сеансом. Нет API → fallback: подготовка промпта без запуска.
- Инструмент vision: нужен для содержательной проверки предоставленных картинок и результатов. Нет vision → не заявлять визуальную проверку.
- ffprobe/ffmpeg: optional для метаданных и декодирования; если отсутствуют, использовать имеющийся просмотрщик/инспектор и честно сократить проверку. Автоустановки нет.
- MiniMax Hub, comfy-cli, LongMedia и VisionPromptor не являются зависимостями этого скилла. Их параметры нельзя выдавать за поля FreeVideo.

## Evidence contract

| claim_supported | collection_method | artifact_path | validator | required_for_done | sanitation_rule |
|---|---|---|---|---|---|
| API доступен | GET root/schema и POST plan | папка задачи/preflight.json | ready, режим, параметры и отсутствие ошибок | для генерации | без Authorization/token |
| Задание создано | POST jobs + GET точного ID | папка задачи/job.json | совпадение ID и сохранённого spec | для генерации | без секретов и чужих заданий |
| Видео получено | скачать returned URL | папка задачи/result.mp4 + metadata.json | непустой файл, метаданные/декодирование | для готового видео | не публиковать чужие материалы |
| Сцена соответствует заказу | просмотреть контрольные кадры и звук | папка задачи/review.md | человек/vision по условиям заказа | для утверждения о визуальном качестве | приватные кадры остаются локальными |

## Final review

Для запроса «только промпт» достаточно режима, структуры, согласованных времён и ролей референсов; сетевых вызовов не нужно. Для готового видео одного succeeded недостаточно. Отметь любую неисполненную проверку. Скилл проверяется отдельно от художественного результата H3.

## Maintenance and rollback

Обновляй по изменению схемы, ошибке пользователя или upstream-правилам; не по числу прошедших дней. Сначала сохрани предыдущую папку, затем проверь helper, /plan и то, что агент видит обновлённый скилл. Для нового локального скилла откат — удалить только его папку; движок, модели и медиа не затрагивать. Не изменяй чужие профили и настройки агента.
